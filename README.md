# MAAAG Shop - Banco de Dados

## Sobre o projeto

Projeto acadêmico de banco de dados desenvolvido utilizando MySQL,
com o objetivo de simular o gerenciamento de uma loja de roupas.

O sistema organiza informações sobre clientes, produtos, fornecedores,
categorias, pedidos e pagamentos.

## Tecnologias utilizadas

- MySQL
- SQL

## Funcionalidades desenvolvidas

- Criação e relacionamento de tabelas.
- Cadastro de clientes, produtos e fornecedores.
- Consultas utilizando SELECT e JOIN.
- Agrupamentos com GROUP BY e HAVING.
- Funções para cálculo de descontos e totais de pedidos.
- Procedures para consultas e cálculos.
- Triggers para controle de estoque, validação de produtos e pagamentos.

## Arquivos

- db_maaag_shop.sql: código SQL completo do projeto.
- explicacao-projeto.pdf: documento com a explicação do projeto.
